# Нулевая смена («Станция Каскад»)

Браузерная 3D-игра от первого лица на социальную дедукцию для 4–8 игроков с онлайн-мультиплеером без регистрации и скачивания. Экипаж ремонтирует орбитальную станцию «Станция Каскад», а один скрытый саботажник пытается сорвать смену.

## Технологии

- **Клиент**: TypeScript, React, Vite, Three.js (процедурные low-poly модели, текстуры и Web Audio без внешних ассетов).
- **Сервер**: Node.js, Express, Socket.IO с полностью авторитетной серверной логикой.
- **Общие модули (`shared/`)**: единые сетевые типы, единая карта «Станция Каскад» (3D-уровень, коллизии, прямая видимость и карта `Tab` строятся из одного источника) и каталог всех 18 интерактивных заданий.

## Установка и запуск

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск в режиме разработки (одна команда поднимает Vite + Express + Socket.IO на порту 3000)
npm run dev
```

Откройте `http://localhost:3000` в настольном браузере.

## Проверка и тесты

```bash
# Проверка типов TypeScript
npm run lint

# Запуск модульных и интеграционного (4 независимых Socket.IO клиента) тестов
npm test

# Продакшен-сборка клиента
npm run build

# Запуск продакшен-сервера (отдаёт dist/ и обслуживает Socket.IO с того же домена)
npm start
```

## Проверка в четырёх вкладках локально

1. Запустите `npm run dev` (или `npm run build && npm start`).
2. Откройте `http://localhost:3000` в первой вкладке, введите позывной (например, `Алекс`) и нажмите **«Создать комнату»**.
3. В лобби нажмите **«Копировать приглашение»** (ссылка вида `http://localhost:3000/?room=XXXXXX`).
4. Откройте скопированную ссылку ещё в **трёх отдельных вкладках** (или окнах инкогнито), введите разные позывные и нажмите **«Войти в отсек»**.
5. В первой вкладке (хозяин комнаты) нажмите **«Начать смену»**.
6. Проверьте роли (ровно 1 саботажник и 3 члена экипажа), клик по экрану для захвата мыши, перемещение `WASD`, схему `Tab`, терминалы `E`, «Эхо датчика» в Командном зале, щит `Q`, отключение света, собрания, голосование и возврат в то же лобби для нового раунда.

## Развёртывание по публичному HTTPS-адресу

Node-сервер (`server.ts`) в продакшене (`NODE_ENV=production`) одновременно раздаёт собранный фронтенд из `dist/` и принимает WebSocket-соединения Socket.IO на том же домене и порту (`PORT`, по умолчанию `3000`).

### Вариант А: Облачный хостинг с автоматическим HTTPS (Cloud Run, Render, Railway, Fly.io)
1. Задайте команду сборки: `npm install && npm run build`.
2. Задайте команду запуска: `npm start` (или `NODE_ENV=production tsx server.ts`).
3. Укажите переменную окружения `PORT` (платформа обычно пробрасывает её автоматически) и при необходимости `APP_URL=https://ваш-домен`.
4. Платформа выдаст публичный `https://...` адрес. Поделитесь ссылкой приглашения (`https://ваш-домен/?room=КОД`) с друзьями — им достаточно открыть её в браузере.

### Вариант Б: Свой VPS + Nginx (reverse proxy с WebSocket и Let's Encrypt)
1. Соберите и запустите сервис через `pm2` или `systemd`:
   ```bash
   npm install
   npm run build
   NODE_ENV=production PORT=3000 npx tsx server.ts
   ```
2. Настройте Nginx с поддержкой WebSocket-апгрейда для Socket.IO:
   ```nginx
   server {
     listen 443 ssl http2;
     server_name example.com;
     # ssl_certificate / ssl_certificate_key (certbot)

     location / {
       proxy_pass http://127.0.0.1:3000;
       proxy_http_version 1.1;
       proxy_set_header Upgrade $http_upgrade;
       proxy_set_header Connection "upgrade";
       proxy_set_header Host $host;
       proxy_set_header X-Forwarded-Proto $scheme;
     }
   }
   ```
3. Выпустите сертификат через `certbot --nginx -d example.com` и приглашайте друзей по ссылке `https://example.com/?room=КОД`.

## Управление в игре

- `WASD` — перемещение (`←` / `→` также вращают камеру без захвата мыши)
- Клик по экрану + мышь — обзор от первого лица
- `E` — взаимодействие с терминалом, кнопкой собрания, «Эхом датчика» или щитом света
- `Q` — активация персонального щита экипажа (2 с после разблокировки)
- `R` — сообщить о найденном выбывшем
- `F` — вывести из строя (только для саботажника вблизи и в прямой видимости)
- `Tab` — карта «Станции Каскад» (только ваше положение и ваши задания)
- `Esc` — настройки чувствительности мыши, звук и выход из панели
